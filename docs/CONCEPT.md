# 게임 콘셉트: 터미널 속 마법사

> 가제: **VOICE SHELL** (이름은 팀에서 바꿀 수 있어요)

## 한 문장 소개

**키보드가 고장 난 낡은 터미널 안에서, 목소리로 명령(주문)을 외쳐 오류 몬스터를 물리치고 시스템을 복구하는 마법사 이야기.**

발표 첫 30초에 이 문장이 전달되면 됩니다. 그래서 "왜 목소리로 싸우는지", "왜 화면이 글자로만 되어 있는지"를 세계관이 직접 설명하도록 짰어요.

| 우리 게임의 특징 | 세계관 속 이유 |
|---|---|
| 마이크로 주문을 외친다 | 터미널의 키보드가 고장 나서 **음성 명령**만 통한다 |
| 화면이 전부 아스키 문자다 | 이곳은 **문자로 이루어진 세계**다 |
| 주문이 영어다 | 터미널 명령어는 원래 영어다 |
| 터미널 UI가 투박하다 | 수십 년 된 **낡은 컴퓨터**라서 그렇다 |

## 세계관

버려진 서버실 구석의 낡은 터미널. 누군가 전원을 켜자 문자로 이루어진 세계가 깨어납니다.
하지만 시스템은 오래전부터 **오류 생물**에게 점령당해 있고, 키보드는 응답하지 않습니다.

플레이어는 이 시스템의 **마지막 관리자 마법사**입니다. 목소리로 명령을 외쳐 오류 생물을 하나씩 정리하고, 가장 깊은 곳의 `/root`에 있는 **커널 패닉 드래곤**을 쓰러뜨리면 시스템이 복구됩니다.

## 이름 짓기 규칙

게임 안의 모든 이름을 컴퓨터 용어와 판타지를 섞어서 지어요. 새 요소를 추가할 때 이 표를 참고해 주세요.

### 몬스터 (오류 생물)
| 몬스터 | 정체 | 특징 아이디어 |
|---|---|---|
| 슬라임 | 메모리 누수 | 가만두면 체력이 조금씩 늘어남 |
| 고블린 | 버그 | 공격이 가끔 엉뚱하게 빗나감 |
| 드래곤 (보스) | 커널 패닉 | 체력이 낮아지면 강화 공격만 씀 |

### 주문 (음성 명령)
| 주문 | 터미널 속 의미 |
|---|---|
| fireball | 프로세스 강제 종료 |
| lightning | 과전압 |
| shield | 방화벽 |
| heal | 시스템 복구 |
| ice (1단계 예정) | 프로세스 일시정지 |
| meteor (1단계 예정) | 디스크 포맷 |
| focus (1단계 예정) | 캐시 비우기 (마나 회복) |

### 성장과 탐험
| 게임 요소 | 터미널 속 이름 |
|---|---|
| 마나 (MP) | 메모리 (MEM) |
| 레벨 | 권한 등급: guest → user → admin → **root** |
| 레벨업 | 권한 상승 |
| 던전 | 디렉터리 트리 (`/home` → `/tmp` → `/var/log` → `/root`) |
| 갈림길 | `cd` 할 폴더 고르기 (left / right / forward) |
| 회복 샘 | 백업 파일 |
| 보물 | 패치 파일 (`.patch`) |
| 승리 화면 | `SYSTEM RESTORED` |
| 패배 화면 | `SEGMENTATION FAULT` |

## 화면 톤

- **색**: 검은 바탕에 초록색 글자(옛날 모니터 느낌)를 기본으로, 피격·경고만 빨간색
- **전투 기록**: 시스템 로그처럼 씁니다.
  ```
  [ OK ] fireball 실행: 메모리 누수 슬라임에게 25 데미지
  [WARN] 메모리 누수 슬라임의 공격: 15 데미지
  [FAIL] 명령을 인식하지 못했습니다
  ```
- **입력 안내**: 터미널 프롬프트처럼 `admin@voice-shell:/home$ 주문을 외치세요`

## 오프닝 (게임 시작 10초)

시연 시간이 짧아서, 게임을 켜자마자 콘셉트가 전달되도록 부팅 화면을 넣어요. 아무 키나 누르면 건너뜁니다.

```
VOICE SHELL BIOS v0.1
메모리 검사 ............ [FAIL] 오류 생물 3개체 감지
키보드 ................. [FAIL] 응답 없음
마이크 ................. [ OK ]

음성 명령 모드로 전환합니다.
관리자님, 주문을 외쳐 시스템을 복구해 주세요.
```

## 2분 시연 시나리오

발표 당일에는 `--demo`(빠른 모드)로 실행해요. 몬스터 체력이 낮아져서 2분 안에 끝납니다.

| 시간 | 화면 | 발표자 멘트 예시 |
|---|---|---|
| 0:00 | exe 실행 → 부팅 오프닝 | "키보드가 고장 난 터미널, 목소리만 통합니다" |
| 0:15 | 첫 전투: 메모리 누수 슬라임 | "fireball!" → 큰 글씨 주문 + 피격 연출 |
| 0:40 | shield, heal 사용 | 화면 아래 '듣는 중' 표시와 인식 결과 보여 주기 |
| 1:00 | 승리 → 권한 상승 (레벨업) | "guest에서 user로 권한이 올라갑니다" |
| 1:20 | 보스: 커널 패닉 드래곤 | 마지막 주문 → `SYSTEM RESTORED` |
| 1:50 | 마무리 | 사용한 오픈소스 4개와 음성 인식 실험 결과 한 장 |

음성이 안 먹히는 상황에 대비해, 음성 모드에서도 키보드로 주문을 칠 수 있는 비상 입력을 넣어요.
