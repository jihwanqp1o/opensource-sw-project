# 음성 인식 정확도 실험

Vosk 영어 소형 모델(`vosk-model-small-en-us-0.15`)로 주문이 얼마나 정확히 인식되는지 측정합니다.
같은 녹음을 세 방식으로 인식해 비교합니다.

- **grammar**: 인식할 단어를 주문 목록으로 제한
- **filtered**: grammar + 오인식 필터 (게임에서 실제로 쓰는 방식)
- **free**: 제한 없이 자유 인식

## 실험 방법

```bash
python -m voice.experiment --speaker 이름 --condition quiet
```
- 화면에 나오는 말("fireball", "hello there" 등)을 Enter를 누른 뒤 말합니다. 말마다 3번씩 반복합니다.
- 주문 4종(fireball, lightning, shield, heal)과 주문이 아닌 말 3종을 녹음합니다.
- 결과는 [voice_results.csv](voice_results.csv)에 한 줄씩 쌓이고, 끝나면 요약표가 출력됩니다.
- `--condition`에는 환경을 적습니다. 예: `quiet`(조용한 곳), `noisy`(시끄러운 곳), `korean-accent`(한국식 발음)
- 녹음 파일은 저장하지 않고 인식 결과만 기록합니다.

측정 지표
| 지표 | 뜻 | 좋은 방향 |
|---|---|---|
| 주문 정답률 | 주문을 말했을 때 맞는 주문으로 인식된 비율 | 높을수록 |
| 오인식률 | 주문이 아닌 말이 주문으로 잡힌 비율 | 낮을수록 |

## 오인식 필터

단어를 주문 목록으로 제한하면 모델이 어떤 말이든 가장 가까운 주문으로 맞추려고 합니다. 그래서 아래 두 조건 중 하나에 해당하면 결과를 버립니다. 기준값은 `config.py`(환경 변수)에서 바꿀 수 있습니다.

| 조건 | 설정 | 기본값 | 근거 |
|---|---|---|---|
| 주문 옆에 모르는 말(`[unk]`)이 섞여 있음 | `VOICE_REJECT_UNKNOWN` | 켜짐 (`1`) | 오인식 2건 모두 "heal [unk]" 형태였고, 정답 22건에는 `[unk]`가 없었음 |
| 단어 신뢰도가 기준보다 낮음 | `VOICE_MIN_CONFIDENCE` | `0.4` | 정답 중 가장 낮은 신뢰도가 0.50 (lightning) |

신뢰도만으로는 부족했습니다. 한국식 발음의 "hello there"는 `heal`을 신뢰도 1.00으로 잡았기 때문입니다.

## 1차 결과: TTS 음성 (2026-11-11)

사람 목소리 실험 전 기준값으로, Windows 음성 합성(TTS)으로 만든 wav 파일을 썼습니다.
주문마다 대표 단어와 별칭 1개씩(예: fireball, fire ball / lightning, thunder) 8개, 주문이 아닌 말 3개입니다.

| 음성 | 조건 | 정답률 grammar | 정답률 filtered | 정답률 free | 오인식률 grammar | 오인식률 filtered |
|---|---|---|---|---|---|---|
| David (영어 남성) | 영어 발음 | 8/8 (100%) | 8/8 (100%) | 7/8 (88%) | 0/3 (0%) | 0/3 (0%) |
| Zira (영어 여성) | 영어 발음 | 8/8 (100%) | 8/8 (100%) | 6/8 (75%) | 1/3 (33%) | 0/3 (0%) |
| Heami (한국어 음성) | 한국식 발음 | 5/8 (62%) | 5/8 (62%) | 0/8 (0%) | 1/3 (33%) | 0/3 (0%) |

free 방식의 오인식률은 세 음성 모두 0%였습니다.

알게 된 것
1. **단어 제한이 정답률을 크게 올립니다.** 특히 한국식 발음에서 0% → 62%로 차이가 큽니다.
2. **대신 오인식이 생깁니다.** "hello there"가 `heal`로 잡혔습니다.
3. **오인식 필터를 더하면 정답률은 그대로 두고 오인식을 없앨 수 있었습니다.** (33% → 0%)
4. **한국식 발음은 fireball, shield를 잘 못 알아듣습니다.** 시연자는 영어식 발음으로 또박또박 말하는 것이 안전합니다.

TTS는 실제 목소리보다 깨끗하기 때문에, 필터 기준값은 2차 결과로 다시 확인해야 합니다.
