# 음성 인식 정확도 실험

Vosk 영어 소형 모델(`vosk-model-small-en-us-0.15`)로 주문이 얼마나 정확히 인식되는지 측정합니다.
같은 녹음을 세 방식으로 인식해 비교합니다.

- **grammar**: 인식할 단어를 주문 목록으로 제한
- **filtered**: grammar + 오인식 필터 (게임에서 실제로 쓰는 방식)
- **free**: 제한 없이 자유 인식

## 실험 방법

```bash
python -m voice.experiment --speaker 이름 --condition quiet
```
- 화면에 나오는 말("fireball", "hello there" 등)을 Enter를 누른 뒤 말합니다. 말마다 3번씩 반복합니다.
- 주문 8종의 대표 단어와 주문이 아닌 말 3종을 녹음합니다.
- 녹음 대신 wav 파일로 하려면 `--wav-dir 폴더`(파일 이름은 `정답__아무거나.wav`), 뭉개진 발음·잡음 같은 나쁜 조건까지 함께 재려면 `--degrade`를 붙입니다.
- 결과는 [voice_results.csv](voice_results.csv)에 한 줄씩 쌓이고, 끝나면 요약표가 출력됩니다.
- `--condition`에는 환경을 적습니다. 예: `quiet`(조용한 곳), `noisy`(시끄러운 곳), `korean-accent`(한국식 발음)
- 녹음 파일은 저장하지 않고 인식 결과만 기록합니다.

측정 지표
| 지표 | 뜻 | 좋은 방향 |
|---|---|---|
| 주문 정답률 | 주문을 말했을 때 맞는 주문으로 인식된 비율 | 높을수록 |
| 오인식률 | 주문이 아닌 말이 주문으로 잡힌 비율 | 낮을수록 |
| 다른 주문으로 | 말한 것과 다른 주문이 발동한 횟수. 턴을 넘기는 것보다 더 나쁜 경우 | 0이어야 함 |

## 오인식 필터

단어를 주문 목록으로 제한하면 모델이 어떤 말이든 가장 가까운 주문으로 맞추려고 합니다. 그래서 아래 두 조건 중 하나에 해당하면 결과를 버립니다. 기준값은 `config.py`(환경 변수)에서 바꿀 수 있습니다.

| 조건 | 설정 | 기본값 | 근거 |
|---|---|---|---|
| 주문 옆에 모르는 말(`[unk]`)이 섞여 있음 | `VOICE_REJECT_UNKNOWN` | 켜짐 (`1`) | 오인식 2건 모두 "heal [unk]" 형태였고, 정답 22건에는 `[unk]`가 없었음 |
| 단어 신뢰도가 기준보다 낮음 | `VOICE_MIN_CONFIDENCE` | `0.4` | 정답 중 가장 낮은 신뢰도가 0.50 (lightning) |

신뢰도만으로는 부족했습니다. 한국식 발음의 "hello there"는 `heal`을 신뢰도 1.00으로 잡았기 때문입니다.

## 1차 결과: TTS 음성 (2026-11-11)

사람 목소리 실험 전 기준값으로, Windows 음성 합성(TTS)으로 만든 wav 파일을 썼습니다.
주문마다 대표 단어와 별칭 1개씩(예: fireball, fire ball / lightning, thunder) 8개, 주문이 아닌 말 3개입니다.

| 음성 | 조건 | 정답률 grammar | 정답률 filtered | 정답률 free | 오인식률 grammar | 오인식률 filtered |
|---|---|---|---|---|---|---|
| David (영어 남성) | 영어 발음 | 8/8 (100%) | 8/8 (100%) | 7/8 (88%) | 0/3 (0%) | 0/3 (0%) |
| Zira (영어 여성) | 영어 발음 | 8/8 (100%) | 8/8 (100%) | 6/8 (75%) | 1/3 (33%) | 0/3 (0%) |
| Heami (한국어 음성) | 한국식 발음 | 5/8 (62%) | 5/8 (62%) | 0/8 (0%) | 1/3 (33%) | 0/3 (0%) |

free 방식의 오인식률은 세 음성 모두 0%였습니다.

알게 된 것
1. **단어 제한이 정답률을 크게 올립니다.** 특히 한국식 발음에서 0% → 62%로 차이가 큽니다.
2. **대신 오인식이 생깁니다.** "hello there"가 `heal`로 잡혔습니다.
3. **오인식 필터를 더하면 정답률은 그대로 두고 오인식을 없앨 수 있었습니다.** (33% → 0%)
4. **한국식 발음은 fireball, shield를 잘 못 알아듣습니다.** 시연자는 영어식 발음으로 또박또박 말하는 것이 안전합니다.

TTS는 실제 목소리보다 깨끗하기 때문에, 필터 기준값은 2차 결과로 다시 확인해야 합니다.

## 1-2차 결과: 주문 8개로 늘린 뒤 TTS 음성 (2026-11-16)

상점 주문 4개(ice, meteor, focus, drain)를 추가해 인식할 단어가 13개 → 20개로 늘었습니다. 단어가 많아지면 서로 헷갈리거나 오인식이 늘 수 있어서 다시 측정했습니다. 주문 8개마다 대표 단어와 별칭(예: ice, freeze / focus, meditate) 14개, 주문이 아닌 말 3개입니다.

| 음성 | 정답률 grammar | 정답률 filtered | 정답률 free | 오인식률 grammar | 오인식률 filtered |
|---|---|---|---|---|---|
| David (영어 남성) | 14/14 (100%) | 14/14 (100%) | 13/14 (93%) | 0/3 (0%) | 0/3 (0%) |
| Zira (영어 여성) | 14/14 (100%) | 14/14 (100%) | 12/14 (86%) | 1/3 (33%) | 0/3 (0%) |
| Heami (한국어 음성) | 10/14 (71%) | 10/14 (71%) | 0/14 (0%) | 1/3 (33%) | 0/3 (0%) |

알게 된 것
1. **주문이 2배로 늘어도 영어 발음 정답률은 100%를 유지했습니다.**
2. **틀린 4건은 모두 "알아듣지 못함"이었고, 다른 주문으로 잘못 인식된 경우는 0건**이었습니다. 새 단어끼리 발음이 충분히 달라서 헷갈리지 않습니다.
3. 한국식 발음은 62% → 71%로 오히려 올랐습니다. 새로 넣은 meteor, focus, drain은 한국식 발음으로도 잘 알아들었고, 여전히 fireball과 shield가 어려웠습니다.

## 1-3차 결과: 뭉개진 발음과 나쁜 환경 (2026-11-16)

TTS는 발음이 너무 정확해서 실제 시연보다 결과가 좋게 나옵니다. 그래서 같은 녹음을 일부러 망가뜨려 다시 쟀습니다 (`--degrade`). 게임에서 실제로 쓰는 방식(filtered) 기준입니다.

| 변형 | 흉내 내는 상황 |
|---|---|
| 빠른 TTS | 말하는 속도 자체를 빠르게 해서 다시 만든 음성 (David, Zira) |
| noise10 | 웅성거리는 교실 (신호 대 잡음 10dB) |
| noise5 | 시끄러운 발표장 (5dB) |
| muffled | 웅얼거림, 입을 덜 벌린 발음, 성능 낮은 마이크 (고음 깎임) |
| quiet | 작게 말하거나 마이크에서 멂 (소리 15%) |
| fast | 급하게 말해 발음이 뭉개짐 (1.35배속) |
| cut | 말끝 흐림 (말소리 뒷부분 30% 잘림) |
| mixed | 웅얼거림 + 빠르게 + 잡음 10dB (가장 나쁜 경우) |

| 변형 | 영어 발음 정답률 | 한국식 발음 정답률 | 다른 주문으로 (영어 / 한국식) | 오인식률 (영어 / 한국식) |
|---|---|---|---|---|
| 원본 | 28/28 (100%) | 10/14 (71%) | 0 / 0 | 0/6 / 0/3 |
| 빠른 TTS | 28/28 (100%) | - | 0 / - | 0/6 / - |
| noise10 | 28/28 (100%) | 2/14 (14%) | 0 / 1 | 1/6 / 0/3 |
| noise5 | 26/28 (93%) | 0/14 (0%) | 0 / 0 | 2/6 / 0/3 |
| muffled | 28/28 (100%) | 10/14 (71%) | 0 / 2 | 0/6 / 0/3 |
| quiet | 28/28 (100%) | 10/14 (71%) | 0 / 1 | 0/6 / 0/3 |
| fast | 28/28 (100%) | 7/14 (50%) | 0 / 2 | 0/6 / 0/3 |
| cut | 28/28 (100%) | 11/14 (79%) | 0 / 0 | 0/6 / 0/3 |
| mixed | 7/28 (25%) | 0/14 (0%) | 1 / 0 | 1/6 / 0/3 |

알게 된 것
1. **영어 발음은 웅얼거림, 작은 목소리, 빠른 말, 말끝 흐림에도 100%를 유지했습니다.** 단어를 주문 목록으로 제한한 효과입니다.
2. **가장 큰 적은 잡음입니다.** 한국식 발음은 잡음이 조금만 섞여도(noise10) 71% → 14%로 떨어졌고, 영어 발음도 웅얼거림과 잡음이 겹치면(mixed) 25%까지 떨어졌습니다.
3. **잡음 속에서는 주문이 아닌 말이 `lightning`으로 잡히는 경우가 생겼습니다** (영어 noise10·noise5·mixed에서 4건).
4. **한국식 발음이 뭉개지면 다른 주문으로 잘못 잡히는 경우가 생겼습니다** (6건). 예: ice → shield(protect로 들림), shield → lightning(thunder로 들림), fireball → ice(freeze로 들림).
5. **신뢰도 기준값을 올려도 해결되지 않습니다.** 잘못 잡힌 11건의 신뢰도를 따로 재 보니 0.38~1.0으로 고르게 퍼져 있었고, 4건은 1.0이었습니다. 기준을 0.8로 올리면 잘못된 결과는 11건 중 6건만 걸러지고 맞은 결과 175건 중 23건도 같이 버려집니다. 그래서 `VOICE_MIN_CONFIDENCE`는 0.4로 그대로 둡니다.

시연에 주는 의미
- 잡음은 소프트웨어로 거르기 어려우므로, **입 가까이 오는 헤드셋 마이크**를 쓰고 발표장 스피커 소리가 마이크에 들어가지 않게 합니다.
- 시연자는 한국식 발음보다 **영어식으로 또박또박** 말합니다. 빠르게 말하는 것은 괜찮습니다.
- 그래도 안 되면 키보드 비상 입력(주문을 치고 Enter)으로 넘어갑니다.

## 1-4차 결과: 던전 방향 단어 (2026-11-16)

던전 갈림길에서는 주문 대신 방향(left, right, forward, straight)만 듣습니다. 같은 TTS 음성 3종으로 "left", "right", "forward", "straight", "go left"와 방향이 아닌 말("fireball", "hello there")을 만들고, 원본과 muffled, fast, noise10 변형으로 쟀습니다.

| 필터 | 방향 정답 | 다른 방향으로 | 방향이 아닌 말이 방향으로 |
|---|---|---|---|
| 주문과 같은 필터 (`[unk]` 섞이면 버림) | 42/60 | 1 | 0/24 |
| 방향용 필터 (`[unk]` 필터 끔, 게임에서 쓰는 방식) | 47/60 | 1 | 0/24 |

알게 된 것
1. **영어 발음은 네 단어 모두 변형까지 거의 다 맞았습니다.** "go left"처럼 앞에 말을 붙여도 방향용 필터에서는 인식됩니다.
2. **한국식 발음은 "레프트", "라이트"처럼 끝에 모음이 붙어서 "left [unk]"로 들렸습니다.** 주문에서는 이런 경우를 오인식으로 버리지만, 방향은 고를 것이 2~3개뿐이라 필터를 끄는 쪽이 낫습니다. 이 변경으로 right가 잡히기 시작했고, 방향이 아닌 말이 방향으로 잡힌 경우는 그대로 0건이었습니다.
3. 한국식 "left"는 여전히 알아듣지 못했습니다. forward와 straight는 한국식 발음으로도 잘 됩니다. 게임에서는 갈 수 있는 방향만 듣게 해서 다른 방향과 헷갈릴 가능성을 줄였습니다.
