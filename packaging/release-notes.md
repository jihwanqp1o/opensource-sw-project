## 어떤 파일을 받으면 되나요?

| 파일 | 실행 방법 | 추천 |
|---|---|---|
| **VoiceShell.zip** | 압축 풀기 → `VoiceShell.bat` 더블클릭 | 기본. 어느 Windows PC에서나 실행돼요 |
| VoiceShell.exe | 받아서 바로 더블클릭 | 빠른 실행용. 스마트 앱 컨트롤이 켜진 PC에서는 막힐 수 있어요 |

- Windows 10/11 64비트용이에요. Python을 따로 설치할 필요가 없어요.
- 음성 인식 모델이 들어 있어서 크기가 80MB 정도예요.
- 창을 최대화한 상태에서 플레이해 주세요.

## 경고가 뜰 때
- **"Windows의 PC 보호"**: "추가 정보" → "실행"을 누르면 돼요.
- **exe가 "애플리케이션 제어 정책" 때문에 막힐 때**: 그 PC는 스마트 앱 컨트롤이 켜져 있어요. zip을 받아 주세요. zip은 python.org의 서명된 공식 Python으로 실행해서 막히지 않아요.
- 경고를 아예 피하려면, zip을 오른쪽 클릭 → 속성 → "차단 해제"에 체크한 뒤 압축을 풀어 주세요.

## 조작
타이틀에서 `Enter` 시작, `H` 주문 목록, `Q` 종료. 주문(fireball, lightning, shield, heal)을 말하고 잠깐 멈추면 인식돼요.
